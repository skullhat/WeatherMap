# WeatherMap
 
WeatherMap is a simple web app for checking the weather on a map. You write the name of any city or town, for example Khartoum or Port Sudan, and the map goes to it and shows the weather now: temperature, clouds, humidity and wind. You can also click any place on the map to see its weather.
 
Other things in the app:
 
- Share the weather with your friends
- Save your favourite cities
- See the weather for the next 5 days
Live: https://sudanweather.xo.je/
 
Built with HTML, CSS and JavaScript, with Leaflet and OpenStreetMap for the map and OpenWeatherMap for the weather data.
